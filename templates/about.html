A SMALL TOOL FOR BIG GOALS

Meet StudyFlow.

StudyFlow is a lightweight task manager made for students who want a clear view of their deadlines without another complicated productivity system.

01

Plan with clarity

Add a task with a deadline and a priority, then see what needs your attention first.

02

Make progress visible

Mark tasks complete, move them back to pending when needed, or remove tasks you no longer need.

03

Keep it simple

This learning project uses a Python list instead of a database. Tasks are cleared when the Flask server stops.
